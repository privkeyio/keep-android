A signing group can now be created on the device itself, with members added from the account switcher by scanning each other's codes. If group creation is interrupted, the key share left behind is detected and can be recovered or discarded after device authentication, instead of sitting there unnoticed. The secret used for group creation is held in the device's secure hardware where that hardware can actually use the key, and falls back to the next safest store where it cannot. A remembered decision now applies when a request is refused, not only when it is approved. Account data that cannot be read back is now reported instead of the app starting as though nothing was saved.
